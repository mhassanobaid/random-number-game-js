# 🎯 Random Number Guessing Game

An interactive Random Number Guessing Game built using **HTML, CSS, and Vanilla JavaScript**.

The application generates a random number between 1 and 100, and challenges users to guess the correct number within a limited number of attempts.

## ✨ Features

- Generate a random number between 1 and 100.
- Accept user guesses.
- Provide hints when the guess is too small or too large.
- Display a success message when the correct number is guessed.
- Limit the number of attempts.
- Display a game-over message when attempts are exhausted.
- Restart functionality to start a new game.
- Input validation.

- Vanilla JavaScript

## 🧠 Engineering Judgments

- Generate random numbers within a defined range.
- Validate user input before processing guesses.
- Convert input strings into numeric values.
- Manage game state explicitly.
- Track remaining attempts.
- Prevent additional guesses after the game ends.
- Handle winning and losing conditions.
- Reset all relevant state when restarting.
- Provide meaningful feedback after each interaction.
